# Brightside · Neo-Brutal 亮色网站模板

纯色亮块 + 粗黑描边 + 硬阴影的亮色风格落地页模板。纯 HTML/CSS，零依赖，直接打开 `index.html` 即可预览。

## 包含区块
导航（移动端折叠菜单）· Hero · 跑马灯 · 功能卡片 · 案例 · 价格 · 用户口碑 · 常见问题 · 订阅 CTA · 页脚

## 换色
所有颜色都在 `styles.css` 顶部的 `:root` 变量里：

```css
--yellow: #FFE14D;
--pink:   #FF6FB5;
--mint:   #5CF2B5;
--blue:   #6EB8FF;
--orange: #FF9F45;
--cream:  #FFF8E7; /* 页面底色 */
--ink:    #111111; /* 描边与文字 */
```

## 部署
纯静态文件，可直接放到 Vercel、Netlify 或 GitHub Pages。
